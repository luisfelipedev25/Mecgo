Roteiro

  1. Motorista Início → Pedir socorro → Pneu furado → envia o chamado.
  2. Prestador No painel aparece o pedido de pneu furado → Enviar orçamento.
  3. Motorista Em Acompanhar vê o mecânico se aproximando no mapa → Ver orçamento → Aceitar e pagar → Pagar (valor fica em custódia).
  4. Prestador Mensagens → Ver rota até o cliente. Nos dois celulares, use Simular 1, 2, 3, 4: saiu, perto, chegando, chegou.
  5. Prestador Cheguei ao local → atualiza o status: no local → em atendimento → concluído.
  6. Motorista No chat, Confirmar conclusão → avalia o atendimento.
  7. Prestador Ganhos → vê o repasse e avalia o cliente.

É uma simulação: as duas telas não se comunicam de verdade. Para isso, seria preciso PHP e banco de dados.
